# 快译截图 1.0.0 · 使用说明

## 更新和启动

先右键托盘中的旧版图标，选择“退出”，再打开新的 **快译截图.exe**。程序为单实例，旧进程没有退出时再次打开 EXE 会唤起旧版。

免安装，适用于 Windows 10 / 11 x64，使用系统自带的 .NET Framework（建议 4.8）。不用安装 Python，不用另外下载 OCR 模型。首次识别会展开内置资源，稍有等待；之后复用本地文件。换电脑复制这一个 EXE，再填写 API 地址和 Key 即可。EXE 约 126 MiB，内含全部识别资源，不含个人 Key。

## 首次公开版本：1.0.0

- 选中画圈或方框后，工具一直保持选中，可以连续绘制多个圆圈或方框，直到主动选择其他工具。
- 要移动或缩放已画图形，先选择“移动”工具，再选中图形操作。

## 工具栏调整

- 图标增大至 32 px，点击区域至少 48 × 48 px。
- 工具栏按截图宽度自适应：够宽时一行，不够时自动换行，每行居中。默认置于截图底部，靠近屏幕底边时移至上方，避免按钮出屏。
- 移除底部“翻译完成”等状态文字，以及“重新截图”按钮。正常仅显示图标；异常会在原文/译文按钮右上角显示红点，悬停可查看原因。
- 需要新截图时，使用已设置的全局截图快捷键。

## 已有功能

- 译文按原文字号估算绘制，优先保持字号。连续正文按段落换行；必要时先利用确认没有明显内容的相邻空白，再考虑缩小。按钮内的译文居中。
- 文字默认字号 **36 px**。输入确定后自动选中，拖动文字移动；拖住四角任意一个控制点可等比例缩放文字，双击可编辑。
- 方框、圆圈画完保持当前绘图工具，可连续绘制；切换“移动”工具后可拖动位置，选中图形可拖动四角改变大小。箭头、线条、画笔、数字和马赛克区域同样可以用“移动”工具选中移动。
- 新增 **连续数字标注**：选择圆圈内“1”的图标，每点一下添加 1、2、3……，支持两位数。每次新截图从 1 开始；撤销最后一个数字后，会复用该序号。
- 新增 **马赛克**：选择像素方格图标，拖出要处理的区域。粗细菜单可调整新马赛克颗粒；选中已有马赛克后也可调整。支持移动、缩放、撤销、重做和图片导出。
- 工具栏参考 [Flameshot](https://github.com/flameshot-org/flameshot) 的图标操作形式，采用深色自适应图标布局，悬停显示中文说明。工具顺序为绘图、样式、撤销、切换、复制、保存和关闭，按可用宽度自动换行。图标由本程序绘制。

字号估算来自截图像素，无法取回网页原字体文件；中文与英文的字面高度也不同。新版以接近原字号和阅读大小为目标。空间不足或译文过长时仍可能缩小，无法承诺任意截图逐字等大。

## 截图翻译和标注

1. 运行程序，按 **Ctrl + Alt + Q** 框选文字。
2. 松开鼠标后自动识别、翻译。中文显示在截图内各个原文字区域，工具栏在截图下方，空间不足时移到上方。
3. 点击“显示原文 / 显示译文”切换视图。截图与标注一起保留。
4. 可添加箭头、圈、线、画笔、方框或文字。添加文字后自动进入“移动”，拖动文字可以调整位置，双击文字可编辑；选中文字后可更改颜色和字号。
5. **复制截图、保存桌面成功后，自动关闭本次截图浮窗。** 复制文字只复制内容，继续保留浮窗。复制或保存失败时保留窗口，方便重试。

框选时按 Esc 或右键取消；浮窗内按 Esc 关闭。需要重新截图时按全局截图快捷键。右下角可调整浮窗大小，复制与保存始终使用原截图分辨率，不会因预览缩放而降低清晰度。

## 图标工具栏

鼠标停留在图标上可查看中文名称。移动工具为箭头指针，文字为 T，数字为圆圈 1，马赛克为像素方格，保留原图为盾牌；操作图标依次为撤销、重做、原文/译文、复制图片、复制文字、保存、停止、关闭。图标排列根据截图宽度自动换行。

点击彩色圆点选择颜色；点击线条数字选择粗细；点击 36 选择字号，可用“自定义”输入 6～300 px。文字添加默认 36 px，数字标注采用适合圆形徽标的独立大小。

主界面的“截图取字”只识别原文，“截图与标注”只截图。需要翻译时点击“显示译文”。设置中的“自动复制图片 / 自动保存桌面”针对刚截下来的原图；手动点击工具栏按钮时则输出当前视图及标注。

## 原位排版与图标保留

新版区分独立标签、连续正文和列表，参考原文字号、行距、颜色和粗细绘制译文。保留原有位置，正文先换行，按钮文字居中。过长译文先尝试相邻空白，确实放不下时再缩小。原字形与中文不同，效果以截图实际显示为准。

翻译只修改文字附近，其他图像来自原始截图，不由大模型重新生成。边缘的独立标识会尽量排除在文字遮罩之外。附带的导航示例中，菜单图标、分隔线、三个下拉标识已逐像素验证保留。

**OCR 无法绝对区分“外形像字母的图标”和真正的文字。** 遇到字母型图标、特殊 Logo、图文重叠等情况，使用“保留原图”框住标识即可恢复原图；Ctrl+Z 可撤销保护。该工具适用于任何区域，不限于下拉箭头。其他标注会正常绘制在保护后的图像上。

## 本地 OCR 升级

主识别引擎升级为 **RapidOCR / ONNX**，在 CPU 上运行，模型随 EXE 内置：

- 英语：PP-OCRv5 英文识别模型。
- 默认英语 / 俄语：英文和 PP-OCRv5 东斯拉夫模型结合识别；俄语、乌克兰语模式使用东斯拉夫模型。
- 德语、法语、西班牙语、葡萄牙语、意大利语：PP-OCRv5 拉丁语系模型。
- 简体中文：PP-OCRv4 模型；日语、韩语：PP-OCRv3 模型。
- 文字定位使用 PP-OCRv4；阿拉伯语及原生引擎不兼容时保留 Tesseract 作为后备。

识别在本地进行，不上传截图。升级不能保证每种特殊字体都识别正确。艺术字、低清晰度、模糊重叠文字仍应切换原文核对。选择正确识别语言有助于减少混淆和耗时；只看英文时可以从默认双语言切为“英语”。

## API 和设置

主界面或托盘打开“设置”，可配置 API 地址、Key、模型、提示词、识别语言、截图快捷键、超时、流式、关闭思考、开机启动和托盘启动。

升级时沿用用户本机已保存的地址及 Key。默认 API 地址为 `https://api.apikey.fan`，模型为 `deepseek-flash`。Key 按要求明文存于本机，未打包进 EXE 或源码。翻译仅向配置的 API 地址发送识别文字和提示词，截图及手动标注不发送。

支持根地址、`/v1` 或完整 `/chat/completions` 地址。API 必须提供 OpenAI 兼容聊天接口。流式请求在尚未收到译文时遇到 502 / 503 / 504，会自动尝试一次普通请求。“关闭深度思考”需服务商支持 thinking 参数。

翻译会结合全部区域理解上下文，并按编号分别放回位置。自定义提示词之后会自动附加原位排版的格式要求，不用自行编写 JSON 规则。

开机启动后直接进入托盘；关闭主窗口也会进入托盘。建议把 EXE 放到固定位置，移动后重新保存启动设置，以更新开机启动路径。

## 后台资源和数据位置

托盘等待快捷键时不定时截图、不轮询网络、不请求 API。OCR 子进程仅在识别时运行，完成或取消后退出。关闭浮窗释放图像和标注，后台没有常驻 OCR 模型。进入托盘和释放浮窗时回收不再使用的内存页，无定时内存清理。

开发环境隐藏窗口待机样本：内部开发样本工作集约 **15 MiB**，私有内存约 **24 MiB**，连续 5 秒累计 CPU 时间约 **16 毫秒**，OCR 子进程为 0。识别期间会临时增加内存与 CPU；这些数字不是对其他电脑的固定承诺。

设置文件：`%LOCALAPPDATA%\快译截图\设置.json`；上次备份为 `设置.json.bak`。新版 OCR 资源目录是 `ocr-neural-v3`，旧版资源不影响新版。识别用临时图片在任务结束后清理；仅手动保存或开启自动保存才保留桌面图片。

## 常见问题

- 快捷键无反应：确认托盘中运行着新版，检查快捷键是否冲突。
- 个别文字识错：切换正确语言，放大原文再截图；必要时切换原图核对。
- 标识被识别为文字：用“保留原图”框选该标识，恢复原始内容。
- 401 / 403：检查 Key 与权限；402 / 429：检查余额、额度与频率。
- 404：检查地址和模型名；502 / 503 / 504：服务商暂时异常，稍后 Ctrl+R 重试。
- 翻译遗漏区域或格式错误：Ctrl+R 重试，或换用能遵循结构化输出要求的模型。

上游许可、模型来源及 SHA-256 清单保存在 OCR 资源目录的 `licenses` 文件夹中。
