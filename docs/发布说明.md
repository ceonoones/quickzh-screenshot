# 快译截图 v1.0.1

排版修复预览版，面向 Windows 10 / 11 x64，使用 .NET Framework 4.8。

## 本次变化

- 通用合并同一标题和段落的 OCR 碎片，避免逐词分散翻译；结合版式区分按钮、列表和正文对齐。
- 根据实际字形计算行高，约束译文区域，减少重叠；优先保持字号，给模型提供多行标题的行容量与语义换行要求。
- 对字形遮罩做邻近背景插值，先擦除全部原文、再绘制全部译文，减少色块及区域覆盖。
- 保留截图翻译、原文切换、全部标注和导出功能。
- 首页新增动态 GIF、完整视频及可操作的 HTML 演示，使用合成素材与预设译文。[打开演示](https://ceonoones.github.io/quickzh-screenshot/)。

## 下载与开始使用

普通用户下载 `QuickZhScreenshot-1.0.1-win-x64.exe` 即可运行；需要同时保留使用说明和第三方许可时下载同名 ZIP。首次使用自行配置 API，默认 Ctrl+Alt+Q 截图翻译。升级前请从托盘退出旧版。

完整源码附件 `QuickZhScreenshot-1.0.1-source.zip` 含固定校验的 OCR 资源，可离线构建。GitHub 自动生成的源码包不含大资源，请按 README 先运行准备脚本。

## 验证与边界

Windows 自动检查覆盖 228 项，包含本地 OCR、模拟 API、原位排版、标注、剪贴板、保存及工具栏布局。正式附件由准确标签的 GitHub Actions 构建。

尚未完成跨电脑、不同 DPI / 多屏组合及真实桌面鼠标完整流程验收。OCR 可能识错，过长译文可能缩小；API 效果与速度受所选服务影响。程序未签名，不宣称逐字节可复现或已经安全审计。API Key 明文保存在用户本机，发布附件不包含 Key 或私人配置。
