# 快译截图 v1.0.0

首次公开预览版，面向 Windows 10 / 11 x64，使用 .NET Framework 4.8。

## 本次功能

- 快捷键框选、本地 OCR、大模型自然中文翻译，译文在原文字位置显示。
- 可配置 API 地址、Key、模型、提示词、截图快捷键、开机启动和托盘。
- 大图标工具栏按截图宽度自动换行；方框和圆圈保持工具选中，可连续绘制。
- 文字可移动和四角缩放，支持箭头、数字、马赛克、撤销重做。
- 复制截图、保存桌面成功后自动关闭；文字复制区分原文与译文。

## 下载与开始使用

普通用户下载 `QuickZhScreenshot-1.0.0-win-x64.exe` 即可运行；需要同时保留使用说明和第三方许可时下载同名 ZIP。首次使用自行配置 API，默认 Ctrl+Alt+Q 截图翻译。升级前请从托盘退出旧版。

完整源码附件 `QuickZhScreenshot-1.0.0-source.zip` 含固定校验的 OCR 资源，可离线构建。GitHub 自动生成的源码包不含大资源，请按 README 先运行准备脚本。

## 验证与边界

Windows 自动检查覆盖 205 项，包含本地 OCR、模拟 API、原位排版、标注、剪贴板、保存及工具栏布局。正式附件由准确标签的 GitHub Actions 构建。

尚未完成跨电脑、不同 DPI / 多屏组合及真实桌面鼠标完整流程验收。OCR 可能识错，过长译文可能缩小；API 效果与速度受所选服务影响。程序未签名，不宣称逐字节可复现或已经安全审计。API Key 明文保存在用户本机，发布附件不包含 Key 或私人配置。
