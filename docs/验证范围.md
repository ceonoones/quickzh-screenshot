# 验证范围与发布检查

## 本地构建

公开版本 1.0.1.0 已从整理后的独立源码目录构建，228 项检查通过。OCR 资源由固定 SHA-256 清单确认，程序包和完整源码包按明确文件列表生成并扫描。

## 自动检查

GitHub Actions 的 Windows 检查在 `windows-2022` 环境获取公开资源、核验校验值、执行源码隐私检查、编译并运行完整检查。标签构建从同一个发布提交重新检查，再生成 EXE、便携包、完整源码包和校验文件。查看本仓库 Actions 页面获得实际运行状态；工作流定义本身不等于运行成功。

默认自动检查不访问真实翻译服务，API 流式、异常、取消和回退使用本机 HTTP 模拟服务。英俄识别、字号与坐标、非文字像素、连续圈框、移动缩放、剪贴板及保存使用实际程序逻辑检查。工具栏预览通过实际离屏渲染核对。

## 排版修复与演示

新增多字号、深浅主题、多词标题、双栏、渐变背景恢复、长译文约束、擦除顺序及缓存状态检查。排版算法不按特定截图的文字或坐标分支；复杂纹理恢复是局部估算，不承诺完全无痕。

演示图及视频帧由实际程序离屏绘制，采用虚构内容与固定译文，HTML 独立实现交互示意。开发时在浏览器检查自动播放、分步、连续圈框、文字输入与移动缩放、原文切换、撤销重做、复制菜单、导出和窄屏换行；这不等同于原生程序完整桌面验收。

## 下载验收

发布后的附件需从 GitHub 再下载，逐个与 SHA256SUMS.txt 核对；源代码与发布标签比对，重新检查内嵌资源、ZIP 目录及图片元数据。源码与二进制扫描已知本机身份、个人路径和凭据模式；提交使用项目署名。第三方许可证中的上游作者、邮箱及来源声明按原样保留。

## 尚未覆盖

- 真实桌面鼠标操作的完整使用流程。
- Windows 10 / 11 不同电脑、DPI / 多显示器组合、所有支持语言。
- 所有特殊字体、模糊文字和图文字形混淆。
- 上游原生 OCR 组件的逐字节可复现构建或独立安全审计。
- 每个 API 服务商的真实翻译质量、可用性和延迟。

过往开发样例中有实际 API 调用结果，不能将它解释为所有服务商或所有截图均已验证。下载校验仅确认附件完整性，不等于代码签名或安全认证。
